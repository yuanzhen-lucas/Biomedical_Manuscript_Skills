# Roadmap

## Phase 1 — Trusted literature and evidence foundation

Done in core form: public provider adapters; RIS/NBIB/BibTeX/CSV import; DOI/PMID/trial-ID normalization; identifier deduplication; metadata conflict preservation; search provenance; local text/PDF extraction; evidence and claim models; verification levels; located claim links; retraction/correction metadata when exposed by a provider.

Remaining: validate all live API contracts against current provider behavior; add PMC/open-access full-text resolver under rights-aware policy; add structured corrections/retractions registry; add robust provider-specific pagination/exports and schema migrations.

## Phase 2 — Original research and narrative review

Done in core form: original and narrative skill procedures; placeholder and claim-language triage; numeric token comparison; required-declaration detection; evidence-matrix generation; immutable manuscript-section versions with hashes and text diffs.

Remaining: data-backed manuscript assembly, table/figure consistency, structured narrative synthesis, and semantic claim-support review.

## Phase 3 — Systematic review and meta-analysis

Done in core form: immutable protocol records, report-level screening decisions, human-recorded study-to-report mappings, disagreement detection, AI reviewer labeling, derived counts, exclusion reasons, controlled appraisal records, generic inverse-variance models, binary/continuous transformations, heterogeneity, approximate prediction intervals, and SVG forest plots.

Remaining: provider import reconciliation at review-record level; multi-stage extraction forms; validated instrument-specific RoB workflows; certainty framework workflow; meta-analysis sensitivity/subgroup analyses, standardized effects, multi-arm dependency, zero-event alternatives, influence diagnostics, and independently validated forest/funnel outputs.

## Phase 4 — Submission-level quality control

Done in core form: version-aware guideline registry and routing; reporting checklist completeness states; manuscript triage; reviewer-response placeholders; journal-source and human-approval gates.

Remaining: verified retrieval and parsing of journal instructions, full revision tracking, complete response matrices, AI-use disclosure based on actual project events, and end-to-end submission checklist validation.
