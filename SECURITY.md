# Security policy

## Supported versions

Security reports are accepted for the latest version on the default branch. This project is pre-1.0; no release support window is currently promised.

## Reporting a vulnerability

Please do not publish secrets, patient data, unpublished manuscripts, or an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled; otherwise contact the repository maintainers through their verified GitHub profile and request a private channel.

Include the affected version/file, reproducible steps, impact, and any relevant logs with confidential content redacted. Do not include live credentials.

## Data handling

Project databases and source documents may contain confidential research. The application does not encrypt the database; users are responsible for device and backup security.
