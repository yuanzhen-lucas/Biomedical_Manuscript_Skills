# Statistical interpretation notes

- Report estimates and uncertainty, not only thresholded P values.
- P > 0.05 does not establish equivalence or absence of effect.
- Statistical significance does not establish clinical importance.
- Check denominators, units, analysis populations, missing data, model assumptions, multiplicity, clustering, repeated measures, and prespecification.
- Avoid overinterpreting subgroup results without a credible interaction analysis and suitable prespecification.
- Distinguish confidence intervals, prediction intervals, and reference intervals.
- For meta-analysis, validate effect direction, estimator, dependence, outcome compatibility, heterogeneity, and clinical rationale before pooling.
- Heterogeneity statistics do not identify its cause. Funnel asymmetry is not proof of publication bias.
- Reproduce key statistical output from data and code using independently checked methods before publication.

The repository's implemented meta-analysis routines cover only a limited set of inverse-variance methods; see `docs/limitations.md`.
