# Contributor Code of Conduct

We expect participants to communicate respectfully, considerately, and constructively. Harassment, discrimination, intimidation, personal attacks, and deliberate disruption are not acceptable.

Maintainers may remove or reject contributions that violate these standards. Report conduct concerns privately to the repository maintainers through the project's GitHub contact path; do not publish private or patient information in a report.

This project follows the principles of the Contributor Covenant, version 2.1: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
